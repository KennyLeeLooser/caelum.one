Good Goose

Eine Desktop-Gans für die Taskleiste. Sie merkt sich Notizen und Aufgaben und meldet sich, wenn Claude Code oder Codex auf dich wartet.

DownloadGitHub

Good Goose sitzt in der Taskleiste und hält fest, was im Chat mit der KI anfällt: Notizen, Aufgaben und Roadmaps. Ist eine Aufgabe fertig oder der Kontext fast voll, zeigt sie es mit einer Sprechblase.

Sie kommt als Plugin für Claude Code und Codex und als Windows-Programm.

Was Good Goose kann

  • Notizen, Aufgaben und Roadmaps aus dem Chat
  • Hinweis bei fertigen Aufgaben und vollem Kontext
  • Plugin für Claude Code und Codex
