Caelum 3D-Viewer

3D-Dateien ansehen und als Bild, PDF-Datenblatt oder GIF ausgeben – direkt im Chat von ChatGPT und Claude oder aus Claude Code und Codex.

Im Browser ausprobierenDownloadGitHub

Der Viewer öffnet GLB, glTF, OBJ, STL, 3MF und DXF direkt; FBX, USDZ und BLEND laufen über Blender. 2D-Zeichnungen aus DXF erscheinen in der Draufsicht.

Ohne Installation funktioniert er als Connector in ChatGPT oder claude.ai: Adresse https://api.caelum.one/viewer/mcp hinzufügen, keine Anmeldung nötig. Im Chat lässt sich das Modell drehen, zoomen und als GIF ausgeben.

Zum Ausprobieren gibt es eine Web-Fassung direkt auf der Startseite: Datei hineinziehen, fertig. Die Datei bleibt dabei im Browser.

Was Caelum 3D-Viewer kann

  • Echte 3D-Ansicht im Chat: drehen, zoomen, Animationen, GIF
  • GLB, glTF, OBJ, STL, 3MF, DXF; FBX, USDZ, BLEND über Blender
  • Ansichten Vorne, Hinten, Links, Rechts, Oben, Unten, Iso oder eigene Winkel
  • PNG, JPG, PDF-Datenblatt und GIF
  • 360°-Drehung und Kamerafahrten ohne Abschneiden
