Caelum Vision

Das Handy wird zum Scanner: Fotos aus einer Scan-Sitzung kommen per USB oder WLAN direkt auf den PC und werden wie ein Scan aufbereitet.

Android · baldUpdates

Handy und PC koppeln sich per Code oder QR. Die Bilder landen ohne Umweg über die Cloud auf dem PC und werden aufbereitet wie von einem Flachbettscanner.

Vision ist eine Schnittstelle für die anderen Caelum-Programme. Die App für Android folgt.

Was Caelum Vision kann

  • Koppeln per Code oder QR
  • Übertragung per USB oder WLAN
  • Aufbereitung wie ein Flachbettscanner
  • Schnittstelle für die anderen Caelum-Programme
